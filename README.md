# Dota Survivor — DotA 1 (6.83d) Survivor Fan Mod

A free, non-commercial fan mod of **PokéSurvivor** by JPTER78
(https://github.com/JPTER78/pokesurvivor — play the original at pokesurvivor.com),
reskinned to **DotA Allstars 6.83d** (the Warcraft III classic).

**Play:** open the GitHub Pages site for this repo, choose a hero, survive.

## What's inside
- All **112 DotA 1 heroes** (6.83d roster) as playable partners, with stats
  converted from the archived PlayDota database.
- Hero gacha banners: Sentinel / Scourge x Strength / Agility / Intelligence.
- 103 moves renamed to DotA abilities; items renamed (Heart of Tarrasque,
  Buriza-do Kyanon, Aegis of the Immortal, ...). Sprites are placeholders
  from the original game for now.
